# Vedika Ayurveda — Feature Reference

Complete feature set of the Next.js 14 Ayurveda e-commerce app (storefront + admin + customer accounts). Brand: **Vedika Ayurveda**, INR/India, dosha pills.

## Storefront

- **Home** (`/`) — hero, featured products, dosha (vata/pitta/kapha) section, category tiles, best-sellers, journal teaser.
- **Shop** (`/shop`) — React Query powered listing with filters: category, dosha, tag (Best Seller / New), search, sort (price/rating/newest), and **load-more** pagination.
- **Categories** (`/categories`) + **Category detail** (`/category/[slug]`).
- **Product detail** (`/product/[slug]`) — image gallery, add-to-cart, add-to-wishlist, ingredients/keywords/dosha badges, related products, and a **reviews section** with a `ReviewForm` (writes via `POST /api/reviews`).
- **Search** (`/search?q=`).
- **Cart** (`/cart`) — line-item review, quantity edit, live shipping calculation, **coupon apply**, proceed to checkout.
- **Wishlist** (`/wishlist`).
- **Customer account**
  - `/account` — profile summary + order history.
  - `/account/profile` — edit name/phone/email + change password (`/api/account`, `/api/account/password`).
  - `/account/addresses` — address book CRUD (`/api/addresses`, `/api/addresses/[id]`).
  - `/account/orders/[id]` — past order detail (`/api/orders/[id]`).
- **Checkout** (`/checkout`) — select/create address, payment method (PayU or COD), coupon discount line, order creation (`/api/checkout`); success/failure pages.
- **PayU integration** (`/api/payu/callback`) — test mode skips strict hash verification.
- **Static/info pages** — About, Contact (`/api/contact`), Blog, Journal post detail.
- **Newsletter** — footer signup form posting to `/api/newsletter`; stored as `Subscriber`.
- **Auth** — login/register (`/api/register`), NextAuth credentials (email + password, bcrypt), role-based sessions.

## Admin (`/admin`, role-gated)

- **Dashboard** — KPI cards (revenue, orders, customers, low-stock count), today's orders, recent orders with quick links.
- **Products** (`/admin/products`) — full CRUD; `ProductForm` supports **image upload** to `/api/upload`.
- **Categories** (`/admin/categories`) — CRUD.
- **Blog posts** (`/admin/posts`) — CRUD with image upload.
- **Orders** (`/admin/orders`) — list with status filter + **CSV export**; order detail (`/admin/orders/[id]`) showing items, address, payment info, with status update and mark-paid actions (`GET /api/admin/orders/[id]`).
- **Customers** (`/admin/customers`) — list; customer detail (`/admin/customers/[id]`) with orders, addresses, wishlist (`GET /api/admin/customers/[id]`).
- **Reviews moderation** (`/admin/reviews`) — list + delete (`/api/admin/reviews`, `/api/admin/reviews/[id]`).
- **Coupons** (`/admin/coupons`) — CRUD + public validation (`/api/coupon/validate`, `/api/admin/coupons`, `/api/admin/coupons/[id]`); applied in checkout.
- **Messages / Contacts** (`/admin/contacts`) — contact inbox view + delete (`/api/admin/contacts`, `/api/admin/contacts/[id]`).
- **Subscribers** (`/admin/subscribers`) — newsletter list, export, remove (`/api/admin/subscribers`, `/api/admin/subscribers/[id]`).
- **Settings** (`/admin/settings`) — store name, support email, phone, address, **free-shipping threshold & fee**, social links (`/api/settings`, `/api/admin/settings`).

## Marketing & SEO

- **`/sitemap.xml`** (`app/sitemap.ts`) — static routes + products + categories + published posts.
- **`/robots.txt`** (`app/robots.ts`).
- Root **metadata** with `metadataBase`, OpenGraph, keywords (`app/layout.tsx`).
- **Blog category filter** (`/blog?category=`).
- **Header Shop mega-dropdown** listing live categories (React Query fetched `/api/categories`).
- **Footer newsletter** signup.

## State Management

- **Zustand** — `useCart` (server-synced for logged-in users) and `useWishlist` (localStorage-backed).
- **React Query** (`@tanstack/react-query`) — storefront data (products, categories, header nav, account) with global `QueryClientProvider`.
- **NextAuth session** — role-based access for `/admin` and account routes (edge middleware).

## Data & Infrastructure

- **Prisma ORM** with two targets:
  - **Dev:** local **SQLite** (`file:./dev.db`, `prisma/schema.prisma`).
  - **Prod:** **Neon (Postgres)**. `prisma/schema.postgres.prisma` is auto-generated by `scripts/make-prod-schema.mjs` (only swaps the provider).
- Schema is written SQLite-compatible: no enums (Role/OrderStatus are `String`), list columns (`images`/`ingredients`/`keywords`/`dosha`) are `String` (comma/newline delimited), `Order.number` is a generated `String` (`VD########`).
- Scripts: `db:push` (SQLite), `db:setup:prod` (gen + push + seed Postgres), `vercel-build` (gen Postgres + push + `next build`), `db:seed`.
- **Settings helper** `src/lib/settings.ts` → `getStoreSettings()`; shipping is computed dynamically via `calcShipping(subtotal, settings)` in `src/lib/utils.ts`.
